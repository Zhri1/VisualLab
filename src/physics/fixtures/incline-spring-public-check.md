# 斜面滑块与弹簧 · 公网验收题

上传 [题图](incline-spring-public-check.png)。题图为原创合成，斜面长度和弹簧间距用厘米给出。可用它核对真实识别是否把长度换算成米。

## 题设核对

| 界面条件 | 期望值 |
| --- | --- |
| 重力加速度 | 10 m/s² |
| 斜面倾角 | 45° |
| 斜面长度 | 3.2 m（320 cm） |
| 动摩擦因数 | 0.20 |
| 初速度 | 0 m/s |
| 滑块质量 | 2 kg |
| 坡底到弹簧原长接触端 | 1.5 m（150 cm） |
| 弹簧劲度系数 | 128 N/m |

模板为 `incline_spring`。释放后下滑、无损转向、水平面光滑、滑块与弹簧不连接均为真。

## 运动对照

| 事件 | 距释放时刻 | 核对数值 |
| --- | ---: | --- |
| 释放 | 0 s | 沿斜面加速度约 5.6569 m/s² |
| 到达坡底 | 1.0637 s | 转向后水平向右，速率约 6.0170 m/s |
| 首次接触弹簧 | 1.3130 s | 水平接触位置为 1.5 m |
| 最大压缩 | 1.5093 s | 压缩量约 0.7521 m，速度为零，弹力约 96.27 N |
| 恢复原长并脱离 | 1.7057 s | 向左，水平速度约 −6.0170 m/s |

用 `a = g(sinθ − μcosθ)` 计算斜面加速度，由 `v² = 2aL` 得到坡底速率。水平段匀速，接触时刻等于下滑时间加上间距除以坡底速率。弹簧的角频率 `√(k/m) = 8 rad/s`，由动能与弹性势能相等求最大压缩量。

改弹簧间距为 **2.5 m** 后应用条件，首次接触时刻应延后到约 **1.4792 s**，最大压缩量仍约 **0.7521 m**。看动画、事件时间与字幕是否一起更新。若识别结果缺间距，在核对表补 **1.5 m**，应能恢复上表结果。
